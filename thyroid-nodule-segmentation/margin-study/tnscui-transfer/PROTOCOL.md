# Frozen display-field filter on a different acquisition format

23 November 2026. Evaluate the unchanged TNUI horizontal scanline rule on the labeled training release of TN-SCUI2020. The organizers describe one image per patient. Identify the native challenge IDs in the archive and distinguish a training-partition derivative from an original raster if inspection shows preprocessing. No model or threshold selection on this collection. Keep DDTI and challenge test data out of scoring.

**Primary safety audit.** For every available training image/mask pair with aligned dimensions and interpretable binary foreground, apply scan_bounds from the completed TNUI experiment. Count patients whose reference has any pixel outside the retained field, the number losing >1% and >5% of target area, pooled retained target fraction and worst per-case loss. Count distinct decoded duplicate images and any repeated IDs. Report exact counts for this release; patient linkage is based on the provider's documentation. Define a boundary subgroup before scoring: distance of the most peripheral labeled target row to either retained band boundary is at most 2% of the image height, including any target extending outside. Also report results for the remaining cases. Carry forward the TNUI technical criterion of >=99% pooled retention; for recommending routine use also require zero cases with >5% lost area. These are research thresholds, not clinical certification.

**Paired model check.** Select 160 eligible unique cases by hashing the salt tnscui-field-v1/ plus the case identifier and taking the first 160. Identify exact native grayscale overlaps with the TN3K model's 2,879 source development images and earlier TNUI development images; exclude overlaps and repeated images from inference. Run the identical frozen TN3K grayscale/flip checkpoint on CPU. Compare unchanged full-image predictions with (i) the frozen image-specific rule, and (ii) the fixed TNUI band fractions from the earlier 96-image discovery set. Use identical native-grid targets and outside-field zeroing. Report mean Dice, sensitivity, zero-overlap count, and totals for removed false and true positives. Bootstrap paired image differences 5,000 times (seed 231130). Evidence of useful performance transfer requires a positive lower interval limit versus unfiltered. Report safety and efficacy separately. No further rule tuning or external test scoring on this sample.

**Field interpretation.** Verify source inventory and archive checksum and inspect released dimensions and sample overlays. This is a test of transport to this distributed image format. It does not establish applicability to raw scanner data from this site when upstream cropping and rendering provenance is uncertain.
