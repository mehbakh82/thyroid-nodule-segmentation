All arms use the original TN3K grayscale checkpoint in CPU evaluation mode, the same horizontal-flip probability averaging, 224-pixel long-side input, a 0.5 foreground threshold and zero predicted probability outside the crop. Primary scoring field is the entire native image. Bilinearly interpolate the unpadded probability map into the exact native field seen by the model before applying threshold. The baseline gets the whole image. The image-center and reference-centroid arms get a square window with side round(0.5 × shorter native image dimension), at least one pixel, clamped by translating the entire window inside the field. Use the centroid of the complete binary foreground, including all components, as the reference prompt. Keep truncations and report reference coverage. This arm simulates supplying privileged target location. It does not estimate the performance of an automatic localizer.

Primary contrast: change in image-mean full-field region Dice for reference-centroid versus image-center crop. Report reference-centroid versus full frame and image-center versus full frame alongside it. Secondary diagnostics: an automatic second pass centered on the largest connected component of the whole-image prediction, falling back to image center for empty predictions; score the original prediction restricted to the reference crop to distinguish suppression of distant foreground from changes caused by rerunning the network. The automatic arm gets two inference views per pass and two passes; all other network arms get a single flip-averaged pass. Do not interpret it as a compute-matched comparison. Report overlap, sensitivity, false foreground relative to reference area, zero-overlap cases, cases at or above .5 region Dice, native-grid 95th-percentile boundary distance and two-pixel native-grid surface Dice.
