# Thyroid nodule segmentation in ultrasound

**Reading note for discussion with Dr. Mina Amiri · 21 November 2026**

The four supplied papers point to a common thesis target: delineating thyroid nodules on 2-D B-mode ultrasound using TN3K and DDTI. A question worth testing is whether explicit edge information improves the contour of a poorly defined nodule when a model moves to a different dataset. The evidence already covers attention, handcrafted edge channels, multiscale fusion, and cross-dataset evaluation. The open part of this proposal is the incremental effect on a specified failure mode under a fair transfer experiment.

## Dataset decisions before training

- **TN3K.** The papers describe 3,493 images from 2,421 patients. The commonly used partition has 2,879 training/validation images and 614 test images. WAU-Net uses 2,445/349/699 in original file order. Published Dice values across those partitions answer different comparisons. Record the source, split manifest, image dimensions and mask encoding. Check whether the release permits grouping multiple views from the same patient. [TN3K author release](https://huggingface.co/datasets/haifan-gong/TN3K) · [Original code and fold manifests](https://github.com/haifangong/TRFE-Net-for-thyroid-nodule-segmentation/tree/a2f11b4f3e5cb79b85d1472b6ba489499eef47e7)
- **DDTI.** All four papers describe 637 images. HFA-UNet reports five-fold evaluation; TEM-Net uses 445/63/129; WAU-Net uses 446/64/127. Jeem et al. give the two descriptions above. Obtain the exact 637 image–mask version and its relationship to the original case identifiers. Check duplicate views, image marks, mask alignment and physical spacing. Counts from public manifests establish file membership only. [Original DDTI publication](https://doi.org/10.1117/12.2073532) · [WAU-Net DDTI manifests](https://github.com/apple1986/WAU-Net/tree/096301fdaa1ee5caff08c33a91e8558b6af5cfaa/datasets/DDTI)

## First discriminating experiment

Develop on TN3K. Compare a well-tuned U-Net with a capacity-matched version receiving the TEM-Net-style contrast and gradient channels. Match initialization, augmentation, resolution, training budget and model selection. An input-channel control can use three copies of grayscale. Inspect source-development errors and label examples of missed nodules, leakage into adjacent tissue, and locally inaccurate contours. Define low boundary contrast and relative nodule size on development data before testing. Review examples with Dr. Amiri to see which errors justify further work.

Freeze preprocessing, thresholds and the primary comparison before the DDTI transfer evaluation. Report foreground Dice, a boundary metric and the count of complete misses. Use a clearly specified common grid for pixel distances or verified spacing for millimeters. Average and resample by patient or case where linkage is known. Report the grouping limitation otherwise. Keep a single reference contour's ambiguity visible when interpreting small changes. These steps would test the hypothesis; the four papers alone do not establish novelty or a positive outcome.
